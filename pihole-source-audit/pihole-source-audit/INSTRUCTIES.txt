PI-HOLE SOURCE OVERLAP ANALYSIS

Add analyze_sources.py to the ROOT of your GitHub repository.
Add analyze.yml under .github/workflows/analyze.yml (NOT in repo root).
Do not replace build.py or update.yml. Your existing working blocklist builder stays unchanged.

Go to Actions > Analyze Pi-hole source overlap > Run workflow.
Open finished run > Artifacts > source-coverage-report.
Download the ZIP; open source-coverage.md for easy reading and source-coverage.csv for sorting.
Send the reports back in chat if you want an exact source removal proposal.

The analysis reads all currently configured Full lists, counts sources' exclusive
contributions and overlap with the Balanced core, and finds identical content.
It does NOT automatically delete or replace lists.

Expected resource usage: this analysis is substantial (millions of domains).
Github-hosted runner memory will be used and sources must be reachable.
